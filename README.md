# xiaomai-tk-growth-demo

这是一个用于沉淀“小麦云 TK 视频营销增长平台”产品方案、PRD、状态流、Codex Prompt 和 MVP 可交互 Demo 的私有仓库。

## 当前目标
- 沉淀业务 PRD
- 整理页面结构与状态流
- 设计 Codex Prompt 体系
- 逐步生成 React 可交互 Demo

## 当前业务闭环
客户准入  
→ 店铺/资产/归因准备  
→ 回款账户绑定与自动扣款授权  
→ 授信审批  
→ 项目立项  
→ 执行任务推进  
→ 达人合作  
→ 脚本/视频交付  
→ 素材验收与授权  
→ 小预算测试  
→ 正式投放与消耗占额  
→ 形成项目应收  
→ 自动扣款 / 回款核销  
→ 复盘与续投

## 仓库目录
- `docs/`：产品文档、PRD、状态流、页面结构、演示故事线
- `prompts/`：给 Codex / OMX 使用的 prompt
- `mock/`：mock 数据
- `src/`：后续 demo 代码

## 注意
本仓库仅保存个人整理的产品原型、方法论和 mock 数据。  
不包含任何真实客户数据、公司内部代码、真实账号信息或商业合同内容。
