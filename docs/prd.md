# 小麦云 TK 视频营销增长平台 PRD V0.3

## 产品定位
小麦云 TK 视频营销增长平台，是一套面向小麦云内部增长服务业务的交付中台，用于承接品牌型卖家的 TikTok 增长服务，核心解决客户准入、项目推进、达人合作、素材资产、广告消耗、账单回款与风险控制问题。

## 一期目标
- 跑通最小业务闭环
- 以项目工单为中枢，串联客户、任务、达人、素材、消耗、账单、回款
- 形成基础风控能力
- 为 Codex/OMX 生成 MVP 可交互 Demo 提供稳定输入

## 核心业务闭环
客户准入  
→ 店铺/资产/归因准备  
→ 回款账户绑定与自动扣款授权  
→ 授信审批  
→ 项目立项  
→ 执行任务推进  
→ 达人合作  
→ 脚本/视频交付  
→ 素材验收与授权  
→ 小预算测试  
→ 正式投放与消耗占额  
→ 形成项目应收  
→ 自动扣款 / 回款核销  
→ 复盘与续投

## 一期核心对象
- 客户
- 启动前检查单
- 回款账户绑定记录
- 自动扣款授权记录
- 授信单
- 项目工单
- 执行任务
- 达人合作单
- 素材资产
- 消耗记录
- 账单 / 回款单

## 一期关键页面
- 客户准入页
- 启动前检查页
- 回款账户绑定与扣款授权页
- 授信审批页
- 项目工单详情页
- 达人合作与素材资产页
- 账单回款页
- 客户轻门户

## 当前原则
- 全对象可见，但轻量化
- 项目工单详情页为中枢页
- 自动扣款针对平台对客户的应收，不是 TikTok 平台原生广告扣费
- 客户需完成店铺准备、广告授权、回款账户绑定和自动扣款授权
