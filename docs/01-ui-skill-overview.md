# 01 UI Skill Overview

## 审美方向
整体风格应接近成熟企业 SaaS，而不是营销落地页、数据大屏或视觉概念稿。

审美关键词：
- 清楚
- 克制
- 稳定
- 可信
- 有秩序
- 有业务重量感

避免：
- 大面积渐变
- 过强阴影
- 过度装饰
- 颜色过多
- 花哨但难理解
- ToC 产品感
- 官网感
- 数据大屏感

## 核心原则
1. 先业务语义，后视觉样式
2. 先状态，后细节
3. 先可用，后精致
4. 一个页面只表达一个主问题
5. 风险、阻塞、下一步动作必须前置

## 技术约束
- React + Vite
- UI 优先使用 antd
- 图标优先使用 @ant-design/icons
- 尽量减少新增大段自定义 CSS
- 不随意修改业务含义和页面主目标

## AI 改造边界
AI 在改造页面时：
- 不得擅自改变页面核心业务含义
- 不得把页面做成营销页或大屏
- 不得只改颜色，不改信息结构
- 不得为了“更好看”牺牲状态表达和判断效率
- 不得继续堆大量无意义 CSS

## 当前阶段重点
当前阶段优先做“产品壳”的可信升级，而不是功能深挖。
每次改造优先关注：
- 页面像不像真实 SaaS
- 主问题是否更清楚
- 状态是否更容易读
- 风险和动作是否更靠前

## 当前轮次优先级
优先提升：
- 信息层级
- 状态表达
- 风险前置
- 下一步动作明确性
