# 03 Page Grammar

## 页面标准结构

### A. 页面头部
必须表达清楚：
- 页面名称
- 页面一句话目标
- 当前对象是谁
- 关键状态标签
- 页面级主操作

### B. 核心概览区
优先回答：
- 当前状态
- 当前风险
- 当前关键指标
- 当前最重要动作

推荐组件：
- Card
- Statistic
- Tag
- Badge
- Alert

### C. 主内容区
根据页面类型选择主结构：
- 列表页优先 Table
- 详情页优先 Card + Descriptions
- 流程页优先 Steps
- 多分区页优先 Tabs / Segmented / Collapse

### D. 风险 / 阻塞 / 下一步区
必须尽量靠前。
页面要让用户快速知道：
- 当前最大风险是什么
- 为什么
- 影响什么
- 下一步该怎么做

### E. 补充说明区
用于放说明、依据、弱信息。
不能抢走主结构的注意力。

## 页面优先级规则
一个页面最多只允许有一个真正的主问题。
如果一个页面看起来“什么都有”，说明结构还不够成熟。

## 当前阶段的设计标准
页面优化优先做：
- 信息分层
- 状态统一
- 风险前置
- 操作明确

不优先做：
- 复杂动效
- 额外装饰
- 视觉噱头
