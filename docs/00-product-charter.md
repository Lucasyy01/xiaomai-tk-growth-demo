# 00 Product Charter

## 项目名称
xiaomai-tk-growth-demo

## 项目定位
这是一个用于沉淀“小麦云 TK 视频营销增长平台”产品方案、状态流、Prompt 体系和 MVP 可交互 Demo 的产品雏形仓库。

它不是营销官网，不是大屏，不是视觉作品集。
它的目标是把复杂的跨境增长业务流程，表达成更像成熟 SaaS 的可交互产品形态。

## 当前阶段目标
当前阶段不是做完整商用系统，而是做出一个：
- 逻辑可信
- 界面可信
- 流程可信
- 能表达核心业务价值的产品雏形

## 当前优化路径
本项目分两步推进：

### 第一步：UI 结构成熟化
先基于当前版本做 UI 优化，重点解决：
- 信息层级不清
- 状态表达不统一
- 风险与阻塞不够前置
- 页面还不够像成熟 SaaS

### 第二步：回到业务可用性深挖
在界面结构稳定后，再从业务可用角度重新审视：
- 页面是否真的支撑判断
- 功能是否真的帮助推进
- 哪些模块该成为 MVP 核心功能
- 哪些只是展示，不该继续做重

## 设计目标
本项目的 demo 优化，不以“视觉惊艳”为目标，而以“初步可用、问题导向、可被理解、可被相信”为目标。

如果一个方案更好看但更难理解，优先选择更容易理解的方案。
如果一个方案更完整但更分散，优先选择更聚焦的方案。
如果一个方案像概念稿但不像真实系统，则不采用。

## 本轮目标
本轮不是功能重构，而是让页面更像成熟 SaaS，更利于理解状态、风险与下一步动作。

## 本轮不做
- 不深改业务逻辑
- 不做全站功能重构
- 不追求视觉炫技


## 未来方向
未来有机会从当前项目中演进出一个完整服务，但当前阶段不追求大而全。
当前优先目标是做出一个足够可信的产品雏形，并逐步识别第一个真正可用、可卖的核心场景。
