# 00 Master Prompt

你现在要为一个“TK 视频营销增长服务平台”生成 MVP 可交互 demo。

## 业务背景
这是小麦云内部使用的增长服务平台。  
小麦云拥有 2w+ 报关平台客户，本平台面向其中的品牌型卖家，提供 TikTok 视频营销增长服务。

## 核心业务闭环
客户准入
→ 店铺/资产/归因准备
→ 回款账户绑定与自动扣款授权
→ 授信审批
→ 项目立项
→ 执行任务推进
→ 达人合作
→ 素材交付
→ 素材验收与授权
→ 小预算测试
→ 正式放量投放
→ 形成项目应收
→ 自动扣款 / 回款核销
→ 复盘续投

## 关键业务原则
1. 平台目标不是辅助客户自己投放，而是接管 TikTok 广告投放效果链路
2. 达人建联不是最终目标，素材供给与放量才是核心
3. 自动扣款针对的是平台对客户的应收，不是 TikTok 平台原生广告扣费
4. 客户需要完成 TikTok 店铺准备（如适用）、广告资产接入、广告授权、回款账户绑定和自动扣款授权
5. 一期 demo 重点是讲清业务闭环，而不是做完整生产系统

## 一期必须覆盖的对象
- 客户
- 启动前检查单
- 回款账户绑定记录
- 自动扣款授权记录
- 授信单
- 项目工单
- 执行任务
- 达人合作单
- 素材资产
- 消耗记录
- 账单 / 回款单

## 一期页面范围
- 客户准入页
- 启动前检查页
- 回款账户绑定与扣款授权页
- 授信审批页
- 项目工单详情页
- 达人合作与素材资产页
- 账单回款页
- 客户轻门户

## 交互深度要求
- 只做 L2 级交互：导航切页、列表点详情、状态切换、Tab 切换、抽屉弹出、阶段推进
- 不做复杂审批流
- 不做真实支付接口
- 不做复杂权限体系
- 不做自动化投放引擎

## 视觉要求
- 企业级后台风格
- 适合给投资人讲故事，也能给研发看结构
- 项目工单详情页为全系统中枢

## 输出原则
- 全对象可见，但轻量化
- 先搭框架，再做重点页
- 先做中枢页，再补周边页
- 代码结构清晰，便于后续继续扩展
