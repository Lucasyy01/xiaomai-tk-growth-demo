# 05 Customer Admission Prompt

现在进入下一轮，只深做“客户准入页”。

## 业务定位
这是平台的商机筛选与客户准入页面，不是完整 CRM，也不是销售管理系统。

它的核心作用是：
- 从小麦云客户池中筛出适合进入 TikTok 增长服务流程的客户
- 让内部快速判断哪些客户值得推进
- 让用户一眼看出客户潜力、当前状态、推进建议和下一步动作

## 页面目标
让用户一眼看懂：
- 当前有哪些客户值得推进
- 哪些客户处于待评估 / 可推进 / 待授信 / 待观察状态
- 每个客户的大致品牌潜力、市场适配、品类信息
- 当前建议动作是什么
- 哪些客户可以进入启动前检查

## 页面承接对象
- 客户
- 客户状态
- 商机评分
- 品牌潜力标签
- 市场 / 品类信息
- 推进建议

## 页面必须包含的区块

### 1. 页面头部
展示：
- 页面标题
- 页面说明
- 当前客户池摘要
- 当前可推进客户数

要求：
- 第一屏要说明这是“客户准入页”
- 明确这不是所有客户管理，只是增长服务筛选入口

### 2. 客户列表区
展示每个客户：
- 客户名称
- 品类
- 市场 / 站点
- 客户状态
- 品牌潜力标签
- 商机评分
- 当前负责人

客户状态至少包括：
- 待评估
- 可推进
- 待授信
- 待观察

要求：
- 列表清晰
- 支持轻量筛选感，不做复杂查询系统
- 可推进客户要更突出

### 3. 客户摘要区
点击客户后展示：
- 客户基础信息
- 当前业务判断
- 历史合作信息（轻量）
- 当前潜力说明
- 当前推进建议

要求：
- 只做摘要和说明
- 不做复杂客户画像系统

### 4. 标签与评分区
展示：
- 品牌潜力
- 市场适配
- 投放意愿
- 履约/供货稳定性
- 商机评分

要求：
- 标签要可读
- 不需要复杂评分算法
- 重点是表达“为什么值得推进”

### 5. 下一步动作区
展示：
- 发起启动前检查
- 标记为待观察
- 进入授信流程（如适用）
- 查看客户视角

要求：
- 让用户知道这个客户接下来该做什么
- 不做复杂审批/销售流程

## 页面交互要求
- 点击客户卡片或列表行，可查看客户摘要
- 点击“发起启动前检查”，可跳转到启动前检查页
- 点击“进入授信流程”，可跳转到授信审批页
- 不做真实提交
- 不做复杂表单
- 不做复杂 CRM 功能

## 样式要求
- 与当前整体壳子风格一致
- 像业务筛选工作台，不像销售 CRM
- 标签、评分、状态要清晰
- 可推进客户要有明显优先级

## 数据要求
请基于现有 mock data 扩展客户准入页所需数据，至少包含：
- 客户列表
- 客户状态
- 品牌潜力标签
- 商机评分
- 客户摘要
- 下一步建议
