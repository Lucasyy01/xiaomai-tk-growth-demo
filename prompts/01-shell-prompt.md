# 01 Shell Prompt

请基于项目 PRD、页面结构图和状态机设计，先生成这套 MVP demo 的整体前端壳子。

## 本轮任务目标
只搭整体框架，不深做细节。

## 页面范围
请先建立以下页面路由：
1. 客户准入页
2. 启动前检查页
3. 回款账户绑定与扣款授权页
4. 授信审批页
5. 项目工单详情页
6. 达人合作与素材资产页
7. 账单回款页
8. 客户轻门户

## 要求
1. 使用 React 生成可交互 demo
2. 生成左侧导航
3. 生成顶部栏
4. 页面之间具备基本跳转能力
5. 使用统一的企业后台风格
6. 使用 mock data
7. 项目工单页作为最突出的中枢页入口

## 暂时不要做
- 深做复杂交互
- 深做表单校验
- 实现真实支付逻辑
- 实现复杂状态联动
- 实现复杂权限系统

## 代码要求
- 结构清晰
- 组件可复用
- 便于后续继续补页面
