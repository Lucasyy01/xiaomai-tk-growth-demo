# 09 Creator Assets Prompt

现在进入下一轮，只深做“达人合作与素材资产页”。

## 业务定位
这是 TikTok 业务专业度页面，用来展示达人合作漏斗和素材资产转化过程。

它不是深度达人平台，也不是复杂素材管理系统。

## 页面目标
让用户一眼看懂：
- 达人合作推进到哪一步了
- 当前有多少达人待回复、待寄样、待交付、待授权
- 当前素材从“已通过”到“已授权”再到“可放量”的转化情况
- 当前哪些素材能测、能投、能放量
- 这个页面为什么能体现 TikTok 业务专业度

## 页面承接对象
- 达人合作单
- 达人合作状态
- 素材资产
- 素材状态
- 授权状态
- 测试状态
- 放量状态

## 页面必须包含的区块

### 1. 页面头部
展示：
- 页面标题
- 页面说明
- 当前项目名称
- 当前摘要说明

### 2. 达人合作区
展示摘要指标：
- 待筛选
- 已触达
- 已回复
- 洽谈中
- 已确认
- 待寄样
- 待交付
- 待授权

要求：
- 更像合作漏斗摘要，不做复杂建联系统

### 3. 达人合作列表区
展示：
- 达人名称
- 国家 / 垂类
- 报价
- 当前状态
- 授权意愿
- 当前阻塞项

### 4. 素材资产摘要区
展示：
- 总素材数
- 已通过数
- 已授权数
- 待测试数
- 测试通过数
- 放量中数
- 不建议复投数

要求：
- 明确表达：
  已通过 ≠ 已授权 ≠ 可放量

### 5. 素材资产列表区
展示：
- 素材名称
- 关联达人
- 当前状态
- 授权状态
- 当前建议动作

### 6. 下一步动作区
展示：
- 查看项目工单详情页
- 查看账单回款页
- 查看当前待授权素材
- 查看当前待交付达人

## 页面交互要求
- 点击达人卡片，可查看轻量详情
- 点击素材卡片，可查看轻量详情
- 点击摘要区，可切换到对应列表
- 不做复杂搜索系统
- 不做复杂编辑能力

## 样式要求
- 与当前整体壳子风格一致
- 更突出 TikTok 业务逻辑
- 状态标签清晰
- 不要做成复杂资产后台

## 数据要求
请基于现有 mock data 扩展本页所需数据，至少包含：
- 达人合作摘要
- 达人列表
- 素材摘要
- 素材列表
- 授权状态
- 测试状态
- 下一步动作建议
